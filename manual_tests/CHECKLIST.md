## Порядок работы
1. Поднять окружение: `docker compose up -d`
2. Собрать модели: `cd dbt_project && dbt seed --profiles-dir . && dbt run --profiles-dir .`
3. Подключиться к БД: `psql -h localhost -U dbt_user -d etl_hub`
4. Последовательно выполнить скрипты из `manual_tests/`, заполняя таблицу выше
5. При обнаружении дефекта — создать Issue в GitHub по шаблону `.github/ISSUE_TEMPLATE/manual_test_defect.md`
6. После исправления — повторить проверку и обновить результат

## Фиксация результатов
- Заполненный чек-лист прикладывается к pull request как комментарий
- Дефекты оформляются через GitHub Issues
- При обнаружении повторяющегося дефекта — создаётся автоматический dbt-тест (см. `tests/`)
